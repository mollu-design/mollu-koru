# 编辑器操作指南

> 本文档面向**终端用户**（运维工程师、图纸设计人员）。纯操作说明，不涉及代码。
> 
> 开发者集成指南见 [editor-user-guide.md](./editor-user-guide.md)。

## 界面布局

![界面布局](/用户手册/界面布局.png)

界面分为四个主要区域：

| 区域 | 位置 | 功能 |
|------|------|------|
| **工具栏 Toolbar** | 顶部 | 保存、预览、撤销重做、缩放、导出、全屏 |
| **Stencil 元件库** | 左侧 | 从分组列表拖入基础图形、电气符号、模板 |
| **画布区** | 中央 | 绘图主工作区，平移/缩放/框选 |
| **属性面板 Properties** | 右侧 | 编辑节点属性、绑定、触发器、多状态、动效 |
| **Minimap 小地图** | 右下角 | 缩略导航，可拖拽定位视口 |

## 画布基础操作

| 动作 | 操作 | 说明 |
|------|------|------|
| **平移画布** | 按住鼠标中键拖动 / 按住空格 + 左键拖动 | 平移整个视口 |
| **缩放** | Ctrl + 鼠标滚轮 / 工具栏 +/- / 滚轮双击 | 默认范围 50%~300% |
| **适应视图** | 工具栏"适应"按钮 | 把所有图元居中并缩放到可见 |
| **选中节点** | 单击节点 | 节点高亮 + 出现 8 个调整手柄 |
| **多选** | Shift + 单击多个节点 / 空白区域拖矩形框 | 批量操作（移动、删除、连线） |
| **取消选中** | 单击空白处 | |

## 从 Stencil 拖入元件

Stencil（左侧面板）按类别分组：

| 分组 | 内容 |
|------|------|
| **基础图形** | 矩形、圆、椭圆、直线、分割器、文本、按钮 |
| **电气符号** | 断路器、刀闸、变压器、CT、PT、避雷器...（取决于项目注册了哪些） |
| **我的模板** | 之前保存的完整图纸缩略图 |
| **自定义图片** | 项目配置的图片资源 |

**操作**：点住元件 → 拖到画布上 → 松开鼠标。

### 拖入后的默认行为

| 情况 | 行为 |
|------|------|
| 普通节点 | 按 dropWidth/dropHeight 创建 |
| `custom-split` | 宽 160、高 80（比普通节点大） |
| 模板 | 弹确认框 → 覆盖当前画布 |
| SVG 符号 | 按注册时指定的尺寸 |

## 连线

| 动作 | 操作 |
|------|------|
| **创建连线** | 鼠标移到节点边缘 → 出现连接桩（小方块） → 点住拖到另一个节点的连接桩上松开 |
| **禁止自连** | 画布不允许节点连到自己 |
| **禁止空连** | 连线两端必须都接到节点上 |
| **选中连线** | 单击连线 → 可拖动端点调整、改样式、删除 |

## 调整节点

| 动作 | 操作 |
|------|------|
| **移动** | 点住节点拖 |
| **缩放** | 选中节点 → 拖 4 角手柄（等比）或 4 边手柄（单方向） |
| **旋转** | 选中节点 → 拖顶部圆形手柄 |
| **对齐参考线** | 拖节点时会出现红色虚线参考线（与其他节点对齐时自动吸附） |

### 多图元统一设置

选中多个节点后，可以一次性修改它们的公共属性（如字体、颜色、连线样式等），无需逐个编辑。

## 属性面板（右侧）

选中一个节点后，右侧属性面板显示该节点的可编辑字段。

### 基础属性

![图元属性面板](/用户手册/图元属性面板.png)

| 字段 | 说明 |
|------|------|
| 名称 Label | 节点下方显示的文字 |
| X / Y | 坐标（手动输入精确值） |
| 宽度 / 高度 | 尺寸 |

### 画布属性面板

不选中任何节点时，右侧显示画布级属性（网格、背景、缩放范围等）。

![画布属性面板](/用户手册/画布属性面板.png)

### 绑定 Binding（重要）

**前提**：节点必须先绑定设备（属性面板里选设备 → 选测点）。

| 绑定类型 | 效果 |
|----------|------|
| 原始值 | 直接显示测点值 |
| 格式化文本 | 加单位 / 小数位（如 `27.1A`） |
| 布尔开关 | 0/1 映射为"合"/"分" |
| 阈值变色 | 越限时节点变色（如电流 > 25A 变红） |
| 多状态切换 | 测点值决定显示哪个 SVG（合闸 SVG / 分闸 SVG） |
| 阈值动画 | 越限时节点闪烁/脉冲 |

## 保存 & 模板

![保存和模板](/用户手册/保存和模板.png)

### 保存图纸

工具栏点 💾 保存 → 弹命名对话框 → 输入图纸名 → 确认。

图纸会保存到后端，下次打开自动加载。

### 模板

常用图纸可以存成模板：
1. 画好一个完整间隔（如"10kV 馈线间隔"）
2. 工具栏点 📋 模板 → 保存为模板 → 输入名称
3. 下次新建图纸时，从 Stencil 的"我的模板"分组拖入

模板是**整图覆盖**——拖入后当前画布内容会被替换（会弹确认）。

## 常见问题

| 问题 | 解决 |
|------|------|
| 刷新浏览器后图纸没了 | IndexedDB 持久化。如果关闭了持久化，后端图纸需要手动点加载 |
| Stencil 里没有我要的符号 | 找项目开发者注册新的 SVG 符号 |
| 连线连不上 | 确认连线两端都接到了连接桩上（节点边缘的小方块），不是只拖到节点上 |
| 预览模式不显示实时值 | 后端需要配置 WebSocket / SSE 推送。测试时用调试面板手动注入数据 |
