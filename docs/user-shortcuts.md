# 快捷键表

> 终端用户速查。开发者见 [context-menu.md](./context-menu.md)。

---

## 画布操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **Ctrl + 滚轮上** | 放大画布 | 以鼠标位置为中心缩放 |
| **Ctrl + 滚轮下** | 缩小画布 | 以鼠标位置为中心缩放 |
| **空格 + 左键拖动** | 平移画布 | 按住空格，画布进入"手型"模式 |
| **滚轮双击** | 适应视图 | 所有图元居中可见 |
| **Ctrl + 0** | 重置缩放 | 回到 100% |

---

## 撤销 / 重做

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **Ctrl + Z** | 撤销 | 支持最多 100 步 |
| **Ctrl + Shift + Z** | 重做 | 恢复撤销的操作 |

---

## 选择

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **单击** | 选中一个节点 | |
| **Shift + 单击** | 追加选中 | 在已有选区上增加 |
| **Ctrl + A** | 全选 | 所有节点 + 连线 |
| **Esc** | 取消选中 | |
| **空白处拖动** | 矩形框选 | 拖过的所有节点选中 |

---

## 节点操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **Delete / Backspace** | 删除选中 | 节点 + 连线一起删 |
| **Ctrl + C** | 复制 | 选中节点复制到剪贴板 |
| **Ctrl + V** | 粘贴 | 粘贴到画布（自动偏移 +20px 避免重叠） |
| **Ctrl + D** | 快速复制 | 选中节点后按一下 → 拖到目标位置 |

---

## 画布内拖动中的操作

| 操作 | 说明 |
|------|------|
| **拖节点时按 Shift** | 水平 / 垂直方向锁定（只能直线移动） |
| **拖节点时出现红色虚线** | 自动对齐到其他节点（参考线吸附） |
| **拖连线时端点变绿** | 表示正确接到了连接桩上（可以松开） |

---

## 画布外（浏览器通用）

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **F11** | 全屏 | 画布进入/退出全屏 |
| **Ctrl + S** | 保存（浏览器） | 如果项目拦截了 Ctrl+S，可能触发图纸保存 |
| **Ctrl + F** | 页面搜索 | 搜索节点名称（浏览器默认） |

---

## 鼠标手势（右键菜单）

选中节点后**右键点击**弹出：

| 菜单项 | 快捷键 | 说明 |
|--------|--------|------|
| 属性 | — | 聚焦右侧属性面板 |
| 绑定 | — | 编辑实时数据绑定 |
| 触发器 | — | 编辑条件触发动作 |
| 复制 | Ctrl+C | 同快捷键 |
| 删除 | Delete | 同快捷键 |
| 组合 / 取消组合 | — | 多选节点打包 |
| 到顶层 / 到底层 | — | 调整 z-index |

> **右键菜单只有在选中节点后才出现**。空白处右键无菜单。

---

## 快捷键冲突说明

| 冲突 | 解决 |
|------|------|
| Ctrl+A 同时被浏览器和画布响应 | 浏览器会选中文本，画布选图元。在画布空白处按才会全选图元 |
| Ctrl+S 浏览器 vs 图纸保存 | 通常项目会拦截 Ctrl+S，弹保存对话框 |
| F11 浏览器全屏 vs 画布全屏 | 画布全屏一般只全屏画布区域，不是整个页面 |
