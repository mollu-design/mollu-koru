# 预览模式使用

> 本文档面向**终端用户**（运维工程师、值班人员）。纯操作说明，不涉及代码。
> 
> 开发者集成指南见 [preview-user-guide.md](./preview-user-guide.md)。

---

## 编辑 vs 预览

| | 编辑模式 | 预览模式 |
|---|---------|---------|
| **能做什么** | 拖元件、连线、改属性、保存 | 看实时数据、触发告警、点击交互 |
| **画布能否移动** | 可以（平移 + 缩放 + 框选） | 可以平移（默认允许，取决于项目配置） |
| **数据变化** | 无（静态设计） | ✅ 实时轮询后端 / 接收 WS 推送 |
| **告警** | 不显示 | ✅ 满足阈值条件时触发告警动画 |
| **点击节点** | 选中 / 编辑属性 | 触发设备详情跳转 / 弹窗（取决于项目配置） |

## 实时数据

### 数据来源

预览模式通过以下方式获取实时值（由项目开发者配置）：

| 方式 | 延迟 | 说明 |
|------|------|------|
| HTTP 轮询 | 3~10 秒 | 周期性拉取最新值 |
| WebSocket 推送 | <1 秒 | 后端主动推送变化的测点 |
| SSE 推送 | <1 秒 | 服务器推送事件 |

### 数据变化时发生什么

1. 画布每 3 秒（或开发者配置的间隔）拉一次最新值
2. 只更新**有变化的测点**（没变化的测点不刷新，省性能）
3. 节点上的绑定配置决定怎么显示新值：

| 绑定类型 | 效果 |
|----------|------|
| 原始值 / 格式化文本 | 文字实时更新 |
| 阈值变色 | 节点颜色随阈值变化（如 220V 绿 / 250V 黄 / 300V 红） |
| 多状态切换 | 显示不同的 SVG（合闸 SVG ↔ 分闸 SVG） |
| 阈值动画 | 越限时节点闪烁 / 脉冲 |
| 告警 | 严重越限时触发告警（Toast / 弹窗 / 音效） |

## 告警

### 什么会触发告警

取决于项目开发者配置的**触发器条件**，常见：

| 条件 | 示例 |
|------|------|
| 电流越限 | ct.ia > 25A |
| 电压异常 | 电压 > 242V 或 < 198V |
| 设备故障 | 状态值 = 'fault' |
| 温度过高 | 变压器温度 > 85℃ |

### 告警等级

| 等级 | 颜色 | 动画 | 说明 |
|------|------|------|------|
| warning | 黄色 / 橙色 | 脉冲 | 轻度告警 |
| critical | 红色 | 快速闪烁 | 严重告警，需要立即处理 |

### 告警推送方式

由项目开发者配置，可能包括：
- 屏幕上 Toast 弹窗
- 页面顶部红色横幅
- 声音告警
- 企业微信 / 钉钉通知
- 自动跳转到告警设备详情页

### 告警抖动说明

有时告警会"告警→恢复→告警→恢复"交替出现（几秒一次）。这是因为测点值在阈值附近波动（如电流 24.8A → 25.2A → 24.9A...）。后端有**防抖**保护，连续 2 次越限才触发告警，恢复后保持 10 秒才清除。如果还频繁抖动，通知运维人员检查传感器或调整阈值。

## 点击节点交互

点击不同类型的节点可能触发不同行为（由项目开发者配置）：

| 节点类型 | 点击效果 |
|----------|---------|
| 断路器 | 弹窗显示详细数据 / 远程合闸操作 |
| 变压器 | 跳转设备详情页 |
| 电流互感器 CT | 显示实时电流波形图 |
| 普通图元 | 高亮或无反应 |

> **如果点击没反应**：可能项目没配置触发器。不是 bug。

## 调试面板（开发者/值班人员排查用）

调试面板默认隐藏，需要项目开发者开启。包含：

### 📋 事件回调日志

实时记录所有用户交互：
- 鼠标点击了哪个节点
- 触发了什么事件（click / dblclick / mouseenter）
- 节点携带的绑定数据

### 📡 数据更新日志

每次实时数据拉取后，记录**有变化的测点**：
```
ct.ia: 24.3 → 27.1  （越限！）
cb.ib: 24.1 → 24.2
tr.temp: 65 → 66
```

### 🔔 触发器动作日志

所有被触发的条件动作：
```
⚠️  ct.ia > 25 → threshold_color（越限变红）
🔔  tr.temp > 85 → alert（高温告警 Toast）
✅  cb.state = "closed" → multi_state_switch（切换合闸 SVG）
```

### 手动注入数据（测试时用）

手动输入测点值，模拟真实设备推送：
```
ct.ia = 27  → 立刻看到节点变红 + 告警
ct.ia = 20  → 恢复正常
cb.state = "open"  → 切换到分闸 SVG
```

### 暂停多状态 / 手动触发

- 暂停多状态：锁定当前 SVG，不跟随测点变化
- 测试动作：手动触发一次告警 / 弹窗，验证配置是否正确

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 预览页一片空白 | 后端图纸没加载 / 图纸数据损坏 | 回编辑页确认图纸存在 |
| 节点不显示实时值 | 绑定没配置 / 后端没推数据 | 打开调试面板看数据更新日志 |
| 告警不触发 | 触发器条件没配置 / 阈值不对 | 打开调试面板手动注入测试值 |
| 点击节点没反应 | 项目没配置点击触发器 | 联系开发者 |
| 画面卡顿 | 图纸图元太多 / 数据推送太频繁 | 考虑拆分图纸 / 降低推送频率 |
| 同一个告警反复出现 | 测点值在阈值附近抖动 | 后端有防抖，通常自动解决 |
